# 🥋 TheoTown Silat Plugin

Plugin **TheoTown** bertema **Pencak Silat Indonesia**, menghadirkan bangunan, tugu, dan padepokan yang terinspirasi dari berbagai perguruan silat Nusantara sebagai elemen budaya di dalam kota.

Project ini dibuat untuk:
- Melestarikan budaya pencak silat melalui game
- Menambah variasi bangunan bertema lokal Indonesia di TheoTown
- Eksperimen pengembangan plugin TheoTown (JSON + pixel art)

---

## ✨ Fitur Utama

- 🗿 **Tugu Perguruan Silat** (landmark / decoration)
- 🏯 **Padepokan Silat** (public building)
- 🎨 **Pixel Art Isometrik** sesuai style TheoTown
- ⚙️ Efek bangunan (kebahagiaan, edukasi, budaya, dll)
- 📦 Format plugin: **Folder / ZIP / MPF (TheoTown compatible)**

---

## 🧩 Daftar Bangunan (Contoh)

- Tugu Pencak Silat  
- Padepokan Silat Nusantara  
- Monumen Perguruan Silat  
- Arena Latihan Silat  

> Catatan:  
> Nama dan desain bersifat **representatif budaya**, bukan untuk klaim resmi organisasi tertentu.

## ▶️ Cara Instalasi

### 💻 PC
1. Download repository ini (ZIP)
2. Extract folder plugin
3. Pindahkan ke: TheoTown/plugins/
4. Jalankan game → Settings → Plugins → Reload

### 📱 Android
1. Download ZIP plugin
2. Extract menggunakan ZArchiver / MT Manager
3. Pindahkan ke: Android/data/info.flowersoft.theotown/files/plugins/
4. Reload plugin di dalam game
